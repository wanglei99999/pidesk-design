# TASK-002：实现 React 工作台前端原型

## 基本信息

- 状态：已完成
- 分支：`task/002-react-prototype`
- 最后更新：2026-08-24
- 关联场景：通用任务工作台
- 依赖任务：无；不接入尚未完成 ADR 的 Pi 运行时

## 目标

在 PiDesk 仓库内建立 React 前端，用模拟数据验证 DeskBuddy Agent 工作台的信息架构、视觉语言和关键交互。参考现有知识库的桌板、纸张、石墨灰、高信息密度和底部输入器设计，不复制其知识库业务代码。

## 本次范围

- 使用 React、TypeScript、Vite 和 Tailwind CSS；
- 前端显示名称为 DeskBuddy，代码和包名继续使用 `pidesk`；
- 实现工作区与最近任务侧栏；
- 实现模拟任务的对话及执行时间线；
- 实现待确认操作的批准与取消交互；
- 实现按需打开、关闭的工作成果预览面板；
- 实现底部自然语言输入器及模拟发送行为；
- 桌面端优先，窄屏下侧栏和成果面板不能遮断主要任务内容；
- 使用合成内容，不访问真实文件、模型或公司系统。

## 不在本次范围

- Pi SDK、Extension、模型和真实文件接入；
- 后端服务、SQLite、认证和数据持久化；
- Electron 打包；
- 完整路由系统、设置页、能力市场和多 Agent；
- 复用知识库 Vue 组件或修改知识库项目；
- 暗色模式和品牌最终定稿。
